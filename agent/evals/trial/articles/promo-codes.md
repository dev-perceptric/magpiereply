---
title: Using a promo code
category: billing-payments
description: How promo codes work and why one might not apply.
---
Enter your code in the **Promo code** box at checkout and click **Apply**.

- One code per order.
- Codes can't be added after an order is placed.
- Codes don't work on gift cards.
- Subscription codes apply to the first shipment only, unless the code says otherwise.

If a code doesn't work, check the expiry date and any minimum order amount in the email it came in.
