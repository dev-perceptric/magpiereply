Self-host in a few commands
# Get the code
$ git clone https://github.com/dev-perceptric/magpiereply
$ cd magpiereply

# Set your secrets and prepare the database
$ cp .env.example .env
$ docker compose -f docker-compose.production.yaml run --rm rails bundle exec rails db:chatwoot_prepare

# Start it
$ docker compose -f docker-compose.production.yaml up -d
