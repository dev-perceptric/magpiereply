01 / Rules

When this happens, do that

A rule starts on an event, checks conditions and runs actions. Set it once and it runs on every matching conversation.

  • Starts when a conversation is created, updated or gets a message
  • Checks inbox, labels, words in the message, custom fields and more
  • Assigns, labels, sets priority, replies, snoozes or resolves
  • Can send a webhook to your own tools
Rule: billing questionsOn
WHEN message created
IF message has "invoice" or "refund"
THEN assign to Billing
THEN add label billing
02 / Macros

Several steps in one click

Save a set of steps as a macro and run it on any conversation. Share it with the team or keep it for yourself.

  • Add labels, assign and change priority
  • Send a message or a private note
  • Snooze or resolve
  • Team macros or personal ones
Macro: hand to engineeringTeam
Add labelbug
Assign teamEngineering
Private noteAdded
Snooze1 day
03 / Saved replies

Answers you write once, with a slash

Type a slash in the reply box and pick a saved reply. The customer's name and other details fill in by themselves.

  • Type / to search saved replies
  • Customer name and fields filled in
  • Shared across the team
  • Edit before sending

04 / Assignment

New chats shared out in turn

Turn on auto-assignment for an inbox and new conversations go to the next available teammate, so nobody gets buried.

  • Round robin among available teammates
  • Only people who are online
  • Per inbox, with its own team
  • Unassign or reassign any time
