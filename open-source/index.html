Up and running with Docker

The production compose file builds the MagpieReply image from the repo. Set your secrets in .env, prepare the database and start it.

# Get the code $ git clone github.com/dev-perceptric/magpiereply $ cd magpiereply # Set your secrets, prepare the database $ cp .env.example .env $ docker compose -f docker-compose.production.yaml \ run --rm rails bundle exec rails db:magpiereply_prepare # Start it $ docker compose -f docker-compose.production.yaml up -d
Run it locally

Work on the code

To run MagpieReply on your own machine without Docker, you need:

  • Ruby, at the version in .ruby-version
  • Node, at the version in .nvmrc, and pnpm
  • PostgreSQL with the pgvector extension
  • Redis
$ cp .env.example .env $ bundle install && pnpm install $ bundle exec rails db:magpiereply_prepare $ pnpm dev # then open http://localhost:3000 and sign up # run the tests $ pnpm test $ bundle exec rspec
