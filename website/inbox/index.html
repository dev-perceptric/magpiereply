Teamwork

Built for a team that shares the load

Everyone works from the same list. Clear owners and statuses mean two people never answer the same customer.

01

Statuses and priorities

Mark each conversation open, pending, snoozed or resolved. Set a priority so urgent tickets rise to the top.

  • Snooze until tomorrow, next week or a date you pick
  • See unattended and mentioned chats in their own views
02

Assignment and teams

Group agents into teams like Billing or Technical support. Assign by hand, or let the inbox hand out new chats in turn to whoever is online.

  • Round-robin assignment for each inbox
  • Business hours with an away message outside them
03

Private notes and mentions

Talk about a ticket right inside the thread. Customers never see private notes. Mention a teammate and they get a ping.

  • Notes stay with the conversation for whoever picks it up next
  • Attach files and screenshots to notes
04

Saved replies and macros

Type a slash to drop in a saved reply. Macros run several steps at once, like reply, add a label and snooze.

  • Saved replies can fill in the customer's name and other fields
  • Share macros with the whole team or keep them private
05

Labels, filters and bulk actions

Tag conversations with labels, save the filters you use every day and update many tickets in one go.

  • Filter by status, inbox, team, label, agent and custom fields
  • Assign, label, resolve or snooze many conversations at once
Automations

Let rules handle the sorting

Set a rule once and it runs every time a conversation matches.

When this happens, do that

Rules can start when a conversation is created, updated or gets a new message. They check the message, the contact and the channel, then act.

  • Assign to a team or agent
  • Add labels and set priority
  • Send a message, an email or a webhook
  • Resolve chats that go quiet after a set time
WHEN Message created
IF Message has "invoice" or "refund"
AND Inbox is Support email
THEN Assign to Billing
THEN Add label: billing
THEN Set priority: high
