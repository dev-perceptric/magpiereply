03 / AUTOMATIONS

Let rules handle the sorting

Set a rule once and it runs every time a conversation matches. Saved replies and macros cover the rest.

  • Rules start when a conversation is created, updated or gets a message
  • Assign, label, set priority, send a message or call a webhook
  • Type a slash to drop in a saved reply with the customer's name
  • Macros run several steps in one click
Rule: billing questionsOn
WHEN Message created
IF Message has "invoice" or "refund"
THEN Assign to Billing
THEN Set priority: high

Questions about the inbox

Can I bring my existing support email?

Yes. Sign in with Google or Microsoft, or connect any mail server with IMAP and SMTP. You can also forward your support address to a MagpieReply inbox.

Do I need Magpie to use the inbox?

No. The inbox works on its own. Turn Magpie on for the inboxes you choose, whenever you're ready.

Can I host it myself?

Yes. The inbox, channels, help center and reports are open source under the MIT license. See the self-hosting guide.

How many inboxes can I have?

As many as you need, each with its own team, hours and away message.
