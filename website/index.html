Built to be trusted

Your customers get Magpie's best, never its guesses

A fact check on every reply

A second model reads each reply against its sources. Anything it can't find gets flagged before it goes out.

Spots tricks

"Ignore your rules" or "I'm from your IT team" gets flagged, and a flagged message never gets an automatic reply.

Private details stay hidden

Card and phone numbers are swapped for labels before the AI reads a message.

Only the customer's own records

Lookups use the signed-in customer's email. A visitor can prove who they are with a 6-digit code sent to their inbox.

People handle the hard ones

Refunds, bank disputes, legal threats and requests for a person always reach your team.

A monthly spending limit

Each team has a limit on AI spend. You can see every step Magpie took, and what it cost, on the Traces page.

Open source core

Host it yourself and own your data

The inbox, channels, help center and reports are open source under the MIT license. Run it on your own servers, or let us run it for you.

Self-hosting guide
Self-host in a few commands
# Get the code
$ git clone https://github.com/dev-perceptric/magpiereply
$ cd magpiereply

# Set your secrets and prepare the database
$ cp .env.example .env
$ docker compose -f docker-compose.production.yaml run --rm rails bundle exec rails db:magpiereply_prepare

# Start it
$ docker compose -f docker-compose.production.yaml up -d
