What's open source

The whole inbox is yours to run

Everything below ships in the open source repo. The AI agent is a separate service that runs on MagpieReply Cloud.

Shared inbox

Statuses, priorities, assignment, teams, labels, private notes, mentions, saved replies, macros and bulk actions.

Every channel

Website chat, email, WhatsApp, Messenger, Instagram, TikTok, Telegram, LINE, SMS, X and an API channel.

Help center

Several portals with custom domains, categories and languages.

Automations

Rules that route, label and reply when a conversation matches, plus auto-resolve.

Reports

Overview, agents, inboxes, teams, labels, satisfaction surveys and live views.

APIs and webhooks

A full app API, a platform API for accounts and users, and a public API for the chat widget and help center.

Self-host

Up and running with Docker

The production compose file builds the MagpieReply image from the repo. Set your secrets in .env, prepare the database and start it.

PostgresWith pgvector

Self-host in a few commands
# Get the code
$ git clone https://github.com/dev-perceptric/magpiereply
$ cd magpiereply

# Set your secrets and prepare the database
$ cp .env.example .env
$ docker compose -f docker-compose.production.yaml run --rm rails bundle exec rails db:magpiereply_prepare

# Start it
$ docker compose -f docker-compose.production.yaml up -d
Run it locally

Work on the code

To run MagpieReply on your own machine without Docker, you need:

  • Ruby, at the version in .ruby-version
  • Node, at the version in .nvmrc, and pnpm
  • PostgreSQL with the pgvector extension
  • Redis

Then open http://localhost:3000 and sign up for the first account.

Local development
$ cp .env.example .env
$ bundle install && pnpm install
$ bundle exec rails db:magpiereply_prepare
$ pnpm dev

# Run the tests
$ pnpm test
$ bundle exec rspec
