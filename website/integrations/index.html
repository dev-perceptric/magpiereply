Questions

Common questions

How does sign-in work?

Click Connect next to an app and sign in to it as you normally would. MagpieReply stores the access it gets in encrypted form, and you can disconnect at any time.

What data can the agent see?

Only records for the customer who is asking. The agent checks who the customer is first, and code fills in their ID for every lookup. The model never picks whose data to read.

Can I limit what the agent does?

Yes. You turn each action on or off and give it a risk level. You can also set amount limits, like refunds up to $50, and a daily cap.

What happens if an app is down?

The agent hands the conversation to your team with a note about which app failed. Nothing runs twice when the app comes back.

Can I ask for an app that is not listed?

Yes. Email hello@magpiereply.com with the app you need.
