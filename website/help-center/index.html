Questions about the help center

Can I use my own domain?

Yes. Point an address like help.yourcompany.com at your help center and it's served there.

Does Magpie read draft articles?

No. Magpie only reads published articles, so you can work on a draft without it reaching customers.

Can Magpie learn from things outside the help center?

Yes. Add websites and files in Settings, AI agent, Knowledge. See how Magpie learns.

Does the help center cost extra?

No. It's part of every plan, and part of the open source core if you host it yourself.
