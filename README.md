# MagpieReply website

The marketing site: plain HTML, CSS and a small script, with no build step.

- `index.html`: the page
- `styles.css`: all styles (brand blue `#0943b0`, Inter)
- `script.js`: pixel mosaics, tab groups and the phone menu
- `assets/`: logos, copied from `public/brand-assets/`

To preview it locally:

```bash
cd website && python3 -m http.server 8080
```

Then open http://localhost:8080.

Before launch, check the placeholder addresses: `hello@magpiereply.com`, `/terms`, `/privacy` and `/app/login`.
